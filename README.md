
# UltraTechPick ⚡

**UltraTechPick** is a simple yet effective tool for exploring and comparing the latest tech products (mobiles and Laptops). Built with modern web technologies, it focuses on usability and clear presentation of key specs. Whether you're a tech enthusiast or just looking to make smarter gadget choices, UltraTechPick is designed to help you easily compare and decide.


## Features

- 🌟 Simple and intuitive user interface
- 📱 Compare the latest mobile devices and other tech gadgets
- 🗝️ Clear presentation of key specifications
- 🔍 Easy exploration and filtering options
- ⚡ Built with Python, JavaScript, HTML, and CSS

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python
- **Other:** Procfile (for deployment)

## Getting Started

### Prerequisites

- Python 3.x
- Node.js and npm (if modifying frontend assets)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yrdaman/UltraTechPick.git
   cd UltraTechPick
   ```

2. **Install Python dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **[Optional] Install frontend dependencies:**
   If there are any, instructions go here.

4. **Run the application:**
   ```bash
   python app.py
   ```
   Or follow the instructions in your main script.

5. **Open your browser and go to:**
   ```
   http://localhost:5000
   ```

## Usage

- Browse and compare the latest tech gadgets.
- Filter and sort products based on specifications.
- View detailed specs for each item.
